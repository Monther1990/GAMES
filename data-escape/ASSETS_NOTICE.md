# Assets notice

- **Characters (boy, girl, Cyber):** original 3D models built from the Cyber Aware owner's own character sheets; shared by
  every game in the series (`public/assets/characters.glb`, `public/assets/faces/`, `public/assets/ui/`). Not modified here.
- **City, road, obstacles, gates, vault:** built in code from simple shapes (`src/run/city.ts`). No model files.
- **Music and sound effects:** generated in the browser with Web Audio (`src/run/sound.ts`). No audio files, no paid service.
- **Font:** Readex Pro, SIL Open Font License 1.1 (`public/fonts/OFL.txt`).
- **Code dependency:** Babylon.js (Apache-2.0).
- **Content:** all names, addresses, codes and links in the situations are fictional (`*.internal` addresses, simulated
  outcomes). `npm run validate` blocks real-looking links, e-mail addresses and numbers.
- **Genre:** a three-lane runner with original theme, art and levels; it does not copy any existing game's characters,
  maps, names or look.
