# درع السيبر

لعبة تصويب من الأعلى ضمن سلسلة «سايبر أوير»: يطير اللاعب (الولد أو البنت) فوق أرض عُمانية، وسايبر أمامه يطلق النار تلقائيًا على البرمجيات الخبيثة. خمس مراحل، في آخر كل مرحلة زعيم ثم ثلاثة أسئلة في الأمن السيبراني. تعمل في المتصفح على الهاتف والحاسوب، وتُضمَّن في المنصة عبر iframe.

الوصف الأصلي في `GAME_BRIEF_AR.md`. الأسئلة كلها كما يقرؤها الطفل في `QUESTIONS_AR.md`.

## التشغيل

```bash
npm install
```

```bash
npm run dev
```

ثم افتح العنوان الذي يظهر (على الهاتف في الشبكة نفسها: عنوان Network).

| الأمر | ما يفعله |
|---|---|
| `npm run build` | يتحقق من البيانات ثم يبني `dist/`، ويحذف منه غرف التجربة |
| `npm test` | ٦٠ اختبارًا للتقييم والاقتصاد والقتال والقوى الخاصة واللعب مع مساند، بلا متصفح |
| `npm run validate` | يفحص تطابق الأسئلة والاقتصاد والنصوص والملفات |
| `npm run fixtures` | يعيد حساب نتائج التقييم المرجعية بعد تعديل `missions.json` |
| `npm run questions` | يعيد توليد `QUESTIONS_AR.md` |

للمطوّر فقط: `?demo=good` يلعب اللعبة تلقائيًا، و`window.__game.simulate(ثوانٍ)` يقدّم الزمن بخطوات ثابتة.

**اللعب مع مساند أثناء التطوير** يحتاج خادم PHP صغيرًا بجانب `npm run dev` (طلبات `/server/` تُحوَّل إليه تلقائيًا):

```bash
C:\xampp\php\php.exe -S 127.0.0.1:5260 -t public
```

### الرفع على XAMPP

1. `npm run build`
2. انسخ محتوى `dist/` كله إلى مجلد داخل `C:\xampp\htdocs` (مثل `htdocs\cyber-shield`). الملف `server/coop.php` جزء منه ولا يحتاج قاعدة بيانات.
3. شغّل Apache، وافتح `http://عنوان-الجهاز/cyber-shield/` من الجهازين.
4. عند أول غرفة ينشئ الملف مجلد `server/rooms` بنفسه (يجب أن يملك Apache حق الكتابة في `server`، وهذا هو الحال في XAMPP على ويندوز). الغرف ملفات صغيرة تُمحى عند إغلاقها أو بعد ساعتين.

على الشبكة نفسها (الواي فاي نفسه) يتصل الجهازان مباشرة بعد أن يتعارفا عبر الخادم، فالحركة سريعة. إن تعذّر الاتصال المباشر تمرّ اللعبة عبر الخادم نفسه: تعمل لكنها أبطأ (نحو خمس صور في الثانية). النشر على الإنترنت عبر `game.omcode.net` مشروح في `..\portal\README.md` (موقع Apache مقيَّد يرى الألعاب فقط). للعب عبر الإنترنت بين شبكتين مختلفتين يُضاف خادم STUN في `src/data/game-config.json`: `"coop": { "stunUrls": ["stun:اسم-الخادم:3478"] }` ثم يُعاد البناء؛ لم أضع خادمًا خارجيًا افتراضيًا حتى لا تُرسَل عناوين اللاعبين إلى طرف ثالث دون قرار منكم.

## اللغتان

اللعبة بالعربية والإنجليزية. زر اللغة في شاشة الاسم وفي القائمة الرئيسية (مكتوب باللغة الأخرى)، أو `?lang=en` و`?lang=ar` في العنوان. الاختيار يُحفظ على الجهاز، وتغييره يعيد تحميل الصفحة. في الإنجليزية الاتجاه من اليسار والأرقام 0-9.

النصوص الإنجليزية ملفات تطابق العربية مفتاحًا بمفتاح: `ui-en.json` و`content-en.json` و`quick-en.json` و`malware-en.json`، وأسماء المراحل والزعماء والأسلحة ونصائح الأسئلة في `names-en.json`. `npm run validate` يرفض البناء إن نقص مفتاح أو بقي حرف عربي في ملف إنجليزي. لاعبان بلغتين مختلفتين يلعبان معًا دون مشكلة، فكل جهاز يعرض نصوصه بلغته.

## طريقة اللعب

- **الحركة**: اسحب إصبعك في أي مكان، أو الأسهم / WASD. إطلاق النار تلقائي. أزرار القتال تعمل بإصبع ثانٍ دون رفع إصبع الحركة.
- **الاقتراب يقوّي الضربة**: كلما اقترب اللاعب من الوحش زاد ضرر سلاحه، حتى مرة ونصف عند خط المواجهة (لا زيادة من مسافة ٩ وحدات فأكثر، والزيادة كاملة من ٤٫٥). القوى الخاصة لا تتأثر بالمسافة. تظهر مرة في القتال رسالة «قريب من الوحش: ضربتك أقوى!».
- **أزرار القوى الخاصة** (أسفل اليسار): لكل قوة مخزّنة زر، والجديدة تظهر فوق السابقة، واضغط أيًّا منها. E أو المسافة تستخدم الأقدم. كل قوة تُستخدم مرة واحدة ثم تزول.
- **زر التطوير** (أسفل اليمين، أو U): يقوّي السلاح المجهّز مستوى واحدًا فورًا ما دام الرصيد يكفي، والسعر مكتوب عليه.
- **زر الأسلحة** (فوق زر التطوير، أو B): يفتح المتجر أثناء القتال لتغيير السلاح أو شراء سلاح، ثم يعود القتال بعدّ تنازلي.
- **الإيقاف المؤقت**: الزر أعلى الشاشة، أو Esc.

### اللعب مع مساند (لاعبان)

زر «لعب مع مساند» في القائمة. اللاعب الأساسي ينشئ غرفة فيظهر رمز من خمسة أحرف وأرقام، ويرسله لصديقه (زر «أرسل الدعوة» يفتح مشاركة الهاتف برابط فيه الرمز، أو يكتب الصديق الرمز بيده). لا بريد إلكتروني ولا حسابات: لقب وشخصية فقط.

- **التقييم للأساسي وحده**: تقدّم المراحل ودرجة المعرفة للاعب الأساسي. بعد الزعيم **يجيب كل لاعب عن أسئلته على جهازه**: للمساند ثلاثة مواقف من مخزونه هو (فلا تتطابق غالبًا مع أسئلة صديقه)، يكسب ريالاتها، وهي عنده تدريب لا يدخل سجل القرارات ولا يغيّر تقدّمه في حملته. من ينتهي أولًا ينتظر الآخر لتبدأ المعركة التالية معًا (وللأساسي زر «ابدأ بدونه»).
- **لكل لاعب ماله**: ريالات العدو لمن أسقطه (والقوة الخاصة تُحسب لمن استخدمها)، ومكافأة الزعيم تُقسم بين الاثنين بنسبة ما ألحقه كل واحد به من ضرر، وحزم الأسئلة لمن أجاب. قواعد الخسارة واحدة: إن خُسرت المعركة أو تُركت عاد رصيد كل لاعب كما كان قبلها. المساند يطوّر سلاحه بزر التطوير في القتال، ويفتح متجر الأسلحة بزر الأسلحة **وعليه درع** ما دام في المتجر (نصف دقيقة على الأكثر)، وله زر «الأسلحة» في بطاقة الانتظار بين المعارك. يُطفأ كسب المساند بـ`"coop": { "supporterEarns": false }` في `game-config.json`.
- **المعركة أصعب**: صحة الأعداء ×١٫٧، صحة الزعماء ×١٫٨، وطلقاتهم أسرع ×١٫٣، ولكل لاعب أربعة قلوب بدل خمسة.
- **الإنعاش**: من تنتهي قلوبه يسقط وينتظر. إذا وقف صديقه بجانبه نحو ثانية أعطاه قلبًا من قلوبه فقام. القلب الأخير لا يُعطى. تُخسر المرحلة إذا سقط الاثنان.
- **الصناديق**: من يضرب الصندوق يأتيه السؤال على جهازه هو (أسئلة كل جهاز من مخزونه، فلا يتشابهان غالبًا)، **والقتال لا يتوقف**: صديقه يكمل، والمجيب عليه درع لا تنقص معه قلوبه حتى يجيب أو ينتهي الوقت. بطاقة النتيجة تُغلق وحدها بعد ٨ ثوانٍ.
- **القوى**: لكل لاعب مخزونه وأزراره. قلوب صندوق القلب لمن أجاب.
- اللاعب الأساسي مع مساند لا يفتح المتجر داخل القتال (له زر التطوير السريع، والمتجر بين المعارك)، ولا تظهر بطاقات تعريف الوحوش حتى لا يتوقف القتال، وزر الإيقاف عند المساند يعرض «غادر».
- **البدء معًا**: حين ينضم الصديق يظهر في بطاقة الغرفة زر «هيا نلعب: المرحلة …»، وبضغطة واحدة يدخل الاثنان المعركة (ومع مساند لا يُطلب تدريب البداية). زر «اختر مرحلة أخرى» يفتح القائمة.
- **تقرير المعركة**: بعد سقوط كل زعيم تظهر بطاقة بمجموع الضرر وعدد الوحوش التي أسقطها كل لاعب (وفي اللعب الفردي أيضًا)، ونجمة لصاحب الضرر الأعلى. المساند يرى أرقام الضرر فوق الوحوش كما يراها الأساسي.
- **الخروج والعودة**: من خرج من المتصفح لحظة، أو نام هاتفه، أو أُعيد تحميل صفحته، يعود إلى اللعب مع صديقه تلقائيًا: كل طرف يحتفظ بمكانه في الغرفة (محفوظ على جهازه عشر دقائق). أثناء غياب المساند يقف عليه درع وينتظره الأساسي ٣٨ ثانية ثم يكمل وحده، والمساند يحاول العودة ٧٥ ثانية. إعادة تحميل صفحة الأساسي تُنهي المعركة الجارية (يعود رصيد الاثنين كما كان) وتبقى الغرفة فيبدآن من جديد.
- إذا غادر المساند بزر «غادر» يكمل الأساسي وحده وتعود الصعوبة والقلوب الخمسة. إذا أغلق الأساسي الغرفة يعود المساند إلى قائمته.

### مسار المرحلة

موجات الأعداء ← تحذير الزعيم ← الزعيم ← مكافأته ← ثلاثة أسئلة (كل إجابة صحيحة تفتح حزمة ريالات) ← BONUS عند ثلاث إجابات صحيحة ← الملخص ← المتجر أو المرحلة التالية.

### صندوق سايبر والقوى الخاصة

يمرّ أثناء الموجات صندوق لامع (مرة في المرحلتين الأوليين، مرتين بعدهما، ومرة عند تحوّل الزعيم إلى طوره الثاني). إن أصبته قبل أن يغادر يتوقف القتال ويظهر سؤال سريع مدته ٢٠ ثانية. الإجابة الصحيحة تعطي قوة خاصة تُخزَّن (ثلاث على الأكثر). أربع من القوى تحمل أسماء حمايات حقيقية ليتعلّم الطفل ما تفعله:

| القوة | أثرها | تظهر من |
|---|---|---|
| قنبلة سايبر | تمحو الأعداء الصغار وطلقاتهم، وتأخذ عُشر صحة الزعيم | المرحلة ١ |
| درع الطوارئ | قلب إضافي وحماية كاملة ٦ ثوانٍ | المرحلة ١ |
| تجميد الفيروسات | يتجمد الأعداء وطلقاتهم ٥ ثوانٍ | المرحلة ١ |
| موجة الليزر | عمود ضوء ٣ ثوانٍ يحرق ما أمام اللاعب ويمحو الطلقات في مساره | المرحلة ٢ |
| الجدار الناري | جدار يصدّ كل طلقات العدو ٦ ثوانٍ | المرحلة ١ |
| التحديث الأمني | السلاح أقوى بمستوى ٨ ثوانٍ | المرحلة ١ |
| مضاد الفيروسات | خط فحص يمسح الشاشة ويضرب كل ما يمرّ عليه | المرحلة ٢ |
| النسخة الاحتياطية | تعمل وحدها: إذا انتهت القلوب يعود اللاعب بقلبين | المرحلة ٢ |
| النبضة العملاقة | تمسح الشاشة وتأخذ ربع صحة الزعيم | المرحلة ٣ |
| **الوعي الشامل** | أقوى قوة: سايبر يطير فوق الساحة ويُسقط القنبلة، فتدمّر كل شيء وتأخذ خُمسَي صحة الزعيم مهما كان درعه | الصندوق الأسود النادر فقط |

**الصندوق الأسود النادر:** صندوق واحد من كل خمسة تقريبًا (ليس في المرحلة الأولى، وواحد على الأكثر في القتال) يكون أسود لامعًا، أمتن وأسرع. فيه سؤالان متتاليان: إجابتان صحيحتان تعطيان «الوعي الشامل»، وإجابة واحدة تعطي قوة عادية، ولا شيء إن أخطأت فيهما.

**صندوق القلب:** إذا نقصت قلوب اللاعب يمرّ صندوق بشكل قلب (مرة في المراحل ١ إلى ٣، ومرتان على الأكثر بعدها). سؤاله غير مكرر، والإجابة الصحيحة تعيد قلبًا أو قلبين بالحظ.

أسئلة الصناديق **تدريبية**: لا تدخل سجل القرارات ولا تؤثر في التقييم، ولذلك جاز أن يكون لها وقت. عددها ٥٠ (عشرة لكل مرحلة)، ولا يتكرر السؤال حتى تنتهي أسئلة المرحلة.

### تعريف الوحوش والموسوعة

أول مرة يظهر نوع جديد من البرمجيات الخبيثة يتوقف القتال لحظة: يبقى الوحش ظاهرًا وعليه ضوء، وفوقه اسمه، وفي أسفل الشاشة بطاقة قصيرة «ما هو؟» و«كيف أحمي نفسي؟» لا تغطيه. بطاقة واحدة على الأكثر في الموجة. كل ما قابله اللاعب يُجمع في «الموسوعة» من القائمة (٣٢ نوعًا مع الزعماء).

### التحدي الأخير: وحش الكود

بعد إنهاء المراحل الخمس يظهر في القائمة زر «التحدي الأخير». هو قتال واحد ضد أصعب زعيم، بلا موجات وبلا أسئلة:

- الوحش مركبة داكنة تحمل شعار OMCode، مرسومًا من ملف الشعار الأصلي دون تغيير مساراته (`scripts/extract-logo.mjs` ← `src/data/omcode-logo.json`).
- القوسان ‹ › يخرجان من الشعار ويُغلقان أمامه كدرع؛ طلقات اللاعب لا تؤثر حينها (عُشر الضرر)، ثم يعودان إلى مكانهما.
- يرمي رموز الكود `{ } < > ; / 0 1` في مراوح وصفوف لها فتحة وحلقات ودوّامة، على ثلاثة أطوار.
- صحته ١١٠٠ (أعلى من كل الزعماء). بسلاح في المستوى ٥ ولاعب يصوّب جيدًا يدوم القتال نحو ٨٠ إلى ٩٠ ثانية في الاختبار الآلي.
- المكافأة ٣٠٠ ريال ووسام «قاهر الكود»، **تُدفع مرة واحدة فقط**؛ الانتصارات التالية للمتعة. المبلغ خارج جدول الـ٢١٠٠ المعتمد.
- لا يدخل التقييم إطلاقًا، ولا يُرسَل للمنصة حدث جديد عنه (بروتوكول الرسائل لم يتغير).

### الخسارة والتنبيه

عند قلبين تنبض حافة الشاشة بالأحمر، وعند القلب الأخير تنبض أقوى مع صوت نبض ورسالة. إذا انتهت الصحة يعود اللاعب إلى بداية المرحلة **برصيده قبل دخولها**: ما جمعه في المحاولة لا يُحتسب، وما اشتراه أو طوّره خلالها يُلغى ويعود ثمنه. الأمر نفسه إن خرج من المرحلة أو أغلق الصفحة قبل هزيمة الزعيم. بعد هزيمة الزعيم يصبح مال المرحلة ثابتًا. القوى الخاصة المستخدَمة لا تعود.

## التقييم (عقد سايبر أوير، لم يتغير)

- ١٥ نقطة تحقق (٣ لكل مرحلة بأوزان ٦ و٧ و٧، المجموع ١٠٠)، ولكل واحدة موقفان يتبدلان عند الإعادة.
- الإجابة الخاطئة ثم الصحيحة تُحتسب ٦٠٪ من وزن السؤال. النجاح من ٧٠٪ مع إكمال الكل. الوقت لا يؤثر.
- تُقيَّم الإجابات الأولى فقط في كل مرحلة؛ الإعادة تدريب يدفع مالًا ولا يغيّر الدرجة.
- النتيجة في المتصفح للعرض؛ الخادم يعيد الحساب من سجل القرارات. الرسائل: `game.started` و`game.decision` و`game.completed` بـ`protocolVersion: 1` إلى `?parentOrigin` فقط.
- المال والأسلحة والقتال للمتعة وليست درجة.

## أين يوجد كل شيء

| المسار | المحتوى |
|---|---|
| `src/data/economy.json` | المراحل، الزعماء، مكافآت الأعداء والأسئلة، الأسلحة التسعة ومستوياتها، أسعار التطوير |
| `src/data/missions.json` | نقاط التحقق وأوزانها والإجابة الآمنة لكل واحدة (ما يعيد الخادم حسابه) |
| `src/data/content-ar.json` | نصوص مواقف الأسئلة الخمسة والأربعين بعد الزعماء (ثلاثة مواقف لكل سؤال) |
| `src/data/quick-ar.json` | أسئلة الصناديق الخمسون ومدة المؤقّت |
| `src/data/malware-ar.json` | وحوش كل مرحلة ونادرها، واسم كل نوع وشرحه وطريقة الحماية منه |
| `src/data/ui-ar.json` | كل نصوص الواجهة |
| `src/sim/` | المحاكاة الخالصة: `world.ts` (القتال والقوى)، `weapons.ts`، `director.ts` (الموجات والزعماء والصناديق)، `economy.ts` |
| `src/view/` | الرسم: `models.ts` (الأعداء والزعماء وقطع البيئة)، `scenery.ts` (الأراضي الخمس)، `arena.ts` (الطلقات والمؤثرات)، `coins.ts` (العملات وأرقام الضرر) |
| `src/core/game.ts` | مسار اللعبة والحفظ والربط، ومنه اللعب مع مساند |
| `src/core/coop.ts` | صورة المعركة التي تُرسَل إلى جهاز المساند وما يرسمه منها |
| `src/net/link.ts` | الاتصال بين الجهازين: مباشر (WebRTC) أو عبر الخادم عند التعذّر |

| `src/ui/` | الواجهة والأنماط |

## المحتوى

**الأسلحة (٩، لكل واحد ٥ مستويات، والتطوير ٦٠ + ١٤٠ + ٢٦٠ + ٤٤٠ = ٩٠٠):** النبض الرقمي (مجاني)، مدفع الشظايا ٣٥٠، قوس الكهرباء ٥٥٠، قرص الارتداد ٦٥٠، الشعاع المركز ٨٠٠، الموجة الخارقة ٩٥٠، الصواريخ المتتبعة ١١٠٠، مدفع البلازما ١٤٥٠، **درع سايبر ١٩٠٠** (الأقوى: سايبر نفسه يُرمى داخل درع ذهبي، يخترق كل شيء ثم يعود).

**شكل السلاح وحركته يقويان مع كل مستوى (حتى المستوى ٥):** الطلقة أكبر وأسطع في كل مستوى، ذيل ضوء من المستوى ٢، قلب أبيض متوهج من المستوى ٤، شرر وحلقة عند الإطلاق في المستوى ٥، وهالة حول سايبر تكبر مع المستوى. ولكل مستوى حركة مختلفة للطلقة نفسها، والمستويان ٣ و٥ يغيّران طريقة الإطلاق.

**الأعداء الصغار: أربعة أشكال مختلفة لكل مرحلة، ووحش نادر خاص بها:**

| المرحلة | الصغار | النادر |
|---|---|---|
| ١ | الفيروس، الدودة، الرسائل المزعجة، طُعم التصيّد | البرنامج المتخفّي (الجمجمة الذهبية) |
| ٢ | مسجّل المفاتيح، برنامج التجسس، كاسر كلمات المرور، البوت | سارق الهوية |
| ٣ | التطبيق المزيف، برنامج الإعلانات، الثغرة، القنبلة المنطقية | ثغرة اليوم صفر |
| ٤ | برنامج التخويف، الباب الخلفي، الملف الملغوم، الشبكة المزيفة | الماسح |
| ٥ | الفيروس المتحوّل، المُنزِّل، لص البيانات، الحساب المزيف | المُعدِّن الخفي |

المدرّع في كل المراحل قفل فدية. طلقات الأعداء كلها تعبر الساحة حتى تخرج من الشاشة (كانت تختفي قبل حافتها على الشاشات العريضة).

**الزعماء:** الرسالة المفترسة (ظرف له فكّ وصنّارة)، قفل الفدية (يغلق درعه)، الدودة العملاقة (رأس وجسم يتبعه وبيض)، الفيروس الأم (كرة أشواك وحلقات)، حصان طروادة (ثلاثة أطوار ويفتح بابه).

**الأراضي:** واحة النخيل والأفلاج، القلاع والحصون، الوادي، رمال الغروب، جبال الليل. المشاهد تتوالى بلا تكرار مباشر.

| الفحص | النتيجة |

| شاشات الدعوة والانتظار | المقاسات الثلاثة: بلا تمرير ولا خروج عن العرض |
| `dist/server/coop.php` بـPHP 8.2 | إنشاء غرفة، انضمام، رفض ثالث، إغلاق |

لم يُختبر بعد:

- **اللعب مع مساند بين جهازين حقيقيين** (هاتفان أو هاتف وآيباد على الواي فاي نفسه): كل ما سبق جُرّب بين نافذتين على حاسوب واحد فقط. المتوقع أن يتصل الجهازان مباشرة، وإن لم يتصلا تعمل اللعبة عبر الخادم أبطأ وتظهر رسالة بذلك.
- اللعب مع مساند عبر الإنترنت بين شبكتين مختلفتين (يحتاج إعداد STUN كما في قسم الرفع).
- Apache في XAMPP نفسه: جُرّب ملف PHP بخادم PHP المدمج، لا بـApache.
- زر «أرسل الدعوة» على هاتف حقيقي: المشاركة والنسخ يحتاجان https أو localhost؛ على عنوان http في الشبكة المحلية تظهر رسالة «أعطِ صديقك الرمز» ويُكتب الرمز يدويًا.
- توازن صعوبة اللعب الجماعي بلاعبَين حقيقيين.
- هاتف حقيقي: اللمس، سرعة الرسم على جهاز ضعيف، الوضع الأفقي.
- الأصوات بالسمع (كلها مولَّدة بالكود).
- نسخة `dist` داخل iframe بعد الإضافات الأخيرة.
- التوازن بلاعبين حقيقيين: صعوبة الزعماء مع القوى الخاصة، وهل ٢٠ ثانية مناسبة لسؤال الصندوق.
- إغلاق الصفحة أثناء سؤال الصندوق: المتوقع من الكود العودة إلى القائمة برصيد ما قبل المرحلة.

## الموسيقى

كلها مولَّدة في المتصفح (`src/core/sound.ts`) بلا ملفات. لكل مرحلة لحنها (`src/core/tunes.ts`): سلّم وأوتار وسرعة وإيقاع وصوت مختلف للمراحل الخمس وللتحدي الأخير، والقائمة تعزف لحن المرحلة الأولى بهدوء. قياس مستوى الصوت: `tests/measure-tunes.dev.js`. الألحان كُتبت بالقواعد وقيس مستواها، ولم تُسمع بأذن بعد.
