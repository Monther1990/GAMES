# ألعاب «سايبر أوير» · Cyber Aware games

ثلاث ألعاب توعية بالأمن السيبراني تعمل في المتصفح (هاتف وحاسوب)، بواجهة على ثيمة منصة cyberaware.om (كريمي، كحلي، ذهبي، خط Readex Pro). «درع السيبر» بجزأيه بالعربية والإنجليزية، و«هروب البيانات» بالعربية فقط.

| المجلد | اللعبة | النوع |
|---|---|---|
| `fighter/` | درع السيبر · Cyber Shield | قتال من الأعلى، أسئلة في الصناديق وتقييم آخر المرحلة، لعب مع مساند |
| `fighterv2/` | درع السيبر ٢ · Cyber Shield 2 | الجزء الثاني: خارطة عُمان، أسلحة جديدة، أسئلة مكالمات، لعب مع مساند |
| `data-escape/` | هروب البيانات · Data Escape | جري في ثلاثة مسارات مع بوابات أسئلة |
| `portal/` | صفحة اختيار اللعبة | HTML و CSS فقط، و`build.mjs` يبني الثلاث ويجمعها في موقع واحد |

في كل مجلد لعبة ملف `README.md` خاص بها، وبنك أسئلتها في `QUESTIONS_AR.md`، ومصادر أصولها في `ASSETS_NOTICE.md`.

## التشغيل والبناء

بُنيت الألعاب واختُبرت على Node.js 22. داخل مجلد أي لعبة:

```bash
npm install
```

```bash
npm run dev
```

```bash
npm test
```

```bash
npm run build
```

`npm run build` يفحص بيانات اللعبة أولًا ثم يُخرج مجلد `dist/`: ملفات ثابتة فقط (HTML و JS وأصول)، بمسارات نسبية (`base: './'`)، فتعمل من أي مسار على المنصة مثل `https://example.om/games/cyber-shield/` دون أي تعديل.

لبناء الثلاث معًا مع صفحة الاختيار (بعد `npm install` في كل لعبة):

```bash
node portal/build.mjs
```

الناتج في `portal/dist/`: الصفحة، و`cyber-shield/` و`cyber-shield-2/` و`data-escape/`.

## الربط مع المنصة

- **التضمين:** كل لعبة صفحة مستقلة؛ تُفتح برابط مباشر أو داخل `iframe`. في `integration/react/CyberAwareGame.tsx` من كل لعبة مكوّن React جاهز (الملف نفسه في الثلاث)، وشرحه في أعلاه:

  ```tsx
  <CyberAwareGame src="/games/cyber-shield/index.html" title="درع السيبر"
    onComplete={({ result, ledger }) => api.post('/games/results', { gameId: result.gameId, ledger })} />
  ```

- **النتيجة:** عند نهاية اللعب ترسل اللعبة إلى الصفحة الحاضنة رسالة `game.completed` (عبر `postMessage`، إلى العنوان الممرَّر في `parentOrigin` فقط) فيها `result` (الدرجة، النسبة، النجاح، نتيجة كل مهمة) و`ledger` (قرارات اللاعب). العقد واحد في الألعاب الثلاث. عاملوا `result` كبيانات عرض: أرسلوا `ledger` إلى خادمكم ودعوه يعيد حساب الدرجة.
- **النصوص:** كلها في `src/data/` (`content-ar.json`، `ui-ar.json`، ونظائرها `-en` في «درع السيبر»)، فتُعدَّل دون لمس الكود.

## اللعب مع مساند (درع السيبر ١ و٢)

يحتاج ملف PHP واحدًا على الخادم: `fighter/public/server/coop.php` (يخرج مع البناء في `dist/server/coop.php`). يكتب غرف اللعب ملفات صغيرة في مجلد `rooms` بجانبه، أو في المجلد الذي يحدده متغير الخادم `COOP_ROOMS_DIR` (الأفضل: خارج مجلد الموقع). لا قاعدة بيانات ولا بيانات شخصية. الجزء الثاني يستخدم الملف نفسه. بدون PHP تعمل اللعبتان كاملتين عدا اللعب مع مساند؛ «هروب البيانات» لا تحتاج خادمًا إطلاقًا.

على الخادم: شغّل PHP لهذا الملف وحده، وامنع تنفيذ أي ملف `.php` آخر في مجلد الألعاب.

## ما ليس في المستودع

`node_modules` و`dist` (يُعاد إنشاؤهما بالأمرين أعلاه)، وسجلّات الخادم، وغرف اللعب، وإعدادات الخادم الأول الذي استضاف الألعاب. لا يوجد في المستودع أي مفتاح أو كلمة سر.
